# Tarjeta de cumpleaños V1

Versión estática y sencilla. Usa HTML, CSS y JavaScript nativo, además de imágenes copiadas del proyecto original en `assets/` (globos, banderines, pastel, gorrito, confeti, bombilla y regalo). No usa paquetes, instalaciones, compilación, imágenes externas ni servicios adicionales.

## Personalizar

Edita `index.html` para cambiar el nombre y el mensaje. La interacción de encender la luz y lanzar confeti está en `js/app.js`.

## GitHub Pages

Sube el contenido de esta carpeta a la raíz de un repositorio de GitHub y activa **Settings → Pages → Deploy from a branch → main → /(root)**.
